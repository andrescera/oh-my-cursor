Create a strategic work plan using Prometheus (the planning agent).

## What Happens

1. Prometheus interviews you to understand requirements
2. Explores the codebase for relevant patterns and context
3. Consults Metis for gap analysis
4. Generates a detailed work plan with parallel execution waves
5. Optionally runs Momus review loop for quality

## The Plan Includes

- TL;DR with estimated effort
- Context from interview and research
- Work objectives with must-have/must-not-have
- Verification strategy
- Execution strategy with parallel waves and dependency matrix
- Detailed TODOs with acceptance criteria and QA scenarios
- Final verification wave
- Commit strategy and success criteria

After the plan is ready, run `/start-work` to begin execution.
